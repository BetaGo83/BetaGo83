# 지도 테스트

저장소 루트에서 Node.js 22 이상으로 실행합니다. Node 내장 모듈만 사용하므로 별도 패키지 설치는 필요하지 않습니다.

```sh
node --test tests/*.test.js
```

| 파일 | 확인하는 위험 |
|---|---|
| `map-scope.test.js` | 기존 연결에 따른 분야·주제 범위, 기업 중복, 표시 상한과 생략, 기존 주변 탐색의 호환 |
| `map-overview.test.js` | 반복 횟수가 제한된 배치, 점 간격과 좌표 안정성, 표시할 레이블의 겹침 |
| `map-news.test.js` | 실제 공개 아카이브의 인덱스·해시, 고유 출처 집계, 한국 날짜 경계, 첫 관측 판별과 엄격한 비교 보류 |
| `map-view-news.test.js` | 실제 화면 제어 코드의 날짜 막대·기업 목록, 첫 화면과 동일 게시본의 새 수집 표시 억제, 과거 재생 범위·선택 유지와 새로고침 실패 처리 |

## 뉴스 비교의 전제

비교 기간은 선택 1일·7일·14일에 대해 각각 바로 앞 7일·7일·14일입니다. 같은 수집 대상의 완료된 한국 날짜별 이력이 확인되고, 비교 기준이 0보다 클 때만 배수를 계산합니다. 마지막 수집일의 미완료 하루나 부분 수집을 포함하면 보류합니다. 선택 기간의 하루 평균이 비교 기간 하루 평균의 2배 이상이고 선택 기간에 3건 이상이라는 조건은 표시 기준이며 통계적 유의성 검정은 아닙니다.

현재 공개 데이터의 보관 시작·종료일이나 게시본의 존재만으로 일별 수집 완료를 추정하지 않습니다. 2026-10-20 점검 자료는 부분 수집 상태이고 날짜별 완료 근거도 없으므로 실제 자료에서 증가 배지를 표시할 수 없습니다. 테스트가 사용하는 완전한 비교 이력은 계산 조건을 검증하기 위한 가상 사례이며 공개 데이터에 추가하지 않습니다. 자료가 없는 날의 미확인과 공개 목록에서 확인한 0건도 구분합니다.

## 브라우저에서 별도로 확인할 동작

화면 제어 테스트는 작은 DOM 대역을 사용하며 실제 브라우저의 글꼴·레이아웃·터치를 재현하지 않습니다. 데스크톱과 좁은 모바일 화면에서는 다음 동작을 확인합니다.

- 세 진입 모드, 분야·주제 선택, 검색과 상세 설정을 키보드와 포인터로 사용할 수 있는지 확인합니다.
- 확대·축소 뒤 이름을 읽고 점·선을 선택할 수 있는지, 근거 링크와 위키 이동이 유지되는지 확인합니다.
- 뉴스 날짜를 바꿔도 위치와 남아 있는 선택이 유지되는지, 재생은 선택 기간 안에서 진행하다 원래 기간으로 돌아오는지 확인합니다.
- 첫 화면과 같은 게시본 재확인에서 새 수집 애니메이션이 생기지 않는지, 부분 수집·실패·미확인 날짜와 움직임 줄이기 설정이 구별되는지 확인합니다.

뉴스 아카이브는 브라우저의 Web Crypto로 공개 파일의 SHA-256을 검증합니다. 브라우저 확인은 HTTPS 또는 Web Crypto를 제공하는 로컬 보안 컨텍스트에서 진행하며, 미리보기 때문에 실제 코드의 검증을 생략하지 않습니다. 자동 검사 통과는 공개 배포 확인이나 실제 iPhone·Android 기기의 사용성 검증을 뜻하지 않습니다.
