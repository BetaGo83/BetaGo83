# 기업 관계 위키

뉴스와 공시의 근거를 따라 기업의 사업, 관계와 주제를 살펴보는 위키입니다.

> AI가 뉴스와 공시를 바탕으로 정리한 참고 자료입니다. 틀린 내용이 있을 수 있으니 원문을 확인하세요. 투자 권유가 아닙니다.

## 읽는 방법

- **기업 페이지**에서 사업 개요, 관계, 최근 이슈와 출처를 읽을 수 있습니다. 국내 상장 기업에는 거래소 업종과 분류 기준일을 함께 표시합니다.
- **주제 안내**는 기술·디지털, 에너지·환경, 산업재·운송, 헬스케어, 소비·문화, 금융에 걸친 **40개 산업·테마**를 다룹니다. 거래소 지수 편입, 공시·거래소 확인, 공식 발표 확인, 추가 확인이 필요한 후보를 구분합니다. 밸류체인 단계는 사업을 설명하는 이름이며 거래소 업종과 다릅니다.
- **기업 관계**는 이 위키에 기업 페이지가 있는 137개 회사 사이의 관계를 보여 줍니다. 처음에는 확인된 현재 관계를 보고, 선택 기업에서 한 단계 또는 두 단계로 범위를 넓힐 수 있습니다. 확인 중·종료 관계는 추가 옵션으로 표시하며, 근거 수준과 날짜를 함께 확인할 수 있습니다.
- **지식 탐색**은 회사·주제·국내 상장사 업종을 다른 표식으로 이어 보여 줍니다. 페이지가 없는 상대는 유형을 단정하지 않는 회색 삼각형입니다. **문서 연결**은 실제 공개 위키의 링크를 따라갑니다. 분류나 문서 링크가 회사 간 거래를 뜻하지는 않습니다.
- **회사 점의 크기**는 지도 종류와 별도로 관계 수 또는 뉴스·공시 수를 고릅니다. 주제·업종·페이지 없는 상대는 고정 크기입니다. **날짜 재생**은 과거 자료가 있는 기업을 강조하며, 실시간 속보 표시와 구별합니다.
- **뉴스 흐름**은 뉴스·공시 제목과 출처를 최신순으로 보여 줍니다. 기업·산업·테마·출처·자료 종류·제목 상태로 찾고 위키와 지도로 이동할 수 있습니다. 제목의 연결은 확인된 기업 관계와 구분합니다.
- **날짜와 자료 수준**을 함께 확인하세요. 계약 체결일, 공시 접수일, 발표일과 검토일은 서로 다를 수 있습니다. 계획이나 협약을 납품 완료로 보지 않습니다.

## 이번 공개본

2026-10-16에는 공식 공시 원문 26건을 확인해 계약·투자·합병·실적과 위험 관련 이슈를 보완했습니다. 모회사·자회사 또는 거래 양측의 공시가 같은 건인지 대조하고, 신규 계약과 기존 계약 변경, 예정과 완료, 잠정치와 확정치, 조사·혐의 단계를 구분했습니다. 한화오션 지분 거래는 매도·매수 측 공시와 PRS 조건을 함께 확인했습니다. 별도로 포스코그룹 공식 발표에서 한화오션의 화물창 실증선 MOU를 확인했습니다. 세부 내용과 원문 링크는 각 기업 페이지에 있으며, 제목 목록 전체의 원문을 확인했다는 뜻은 아닙니다.

2026-10-16 그래프를 **기업 관계·지식 탐색·문서 연결**로 구분했습니다. 앞선 변경은 점 크기와 날짜 재생을 추가했지만 탐색 목적에 따른 구분은 빠져 있었습니다. 회사 주변의 관계는 최대 80개 점, 문서 이웃은 최대 60개 점으로 제한하고 생략 수를 표시합니다. 기존 주소와 공개된 회사·주제 자료는 유지합니다.

지도 종류를 바꿔도 선택 날짜·기간·기사/공시·크기 척도가 이어집니다. 문서 연결은 선택한 회사나 주제의 실제 문서로 열리며, 문서에서 지도로 돌아올 때도 같은 대상을 찾습니다.

2026-10-16에는 **뉴스 흐름**을 추가했습니다. 공식 RSS가 현재 제공하는 기사와 DART 최근 3일 접수 목록에서 공개 대상의 제목·링크·날짜·출처만 골랐습니다. 기사 본문이나 요약문은 싣지 않으며, 공시 원문을 검토한 위키 이슈와 제목 목록을 구분합니다.

현재 목록은 최근 **14일** 안의 공개 대상 가운데 최대 **300건**, 한 페이지 **40건**으로 제한합니다. 수집 시각·대상 기간·확인 실패나 누락 가능성을 표시합니다. 사용자가 요청할 때 한 번 수집하고 검사해 게시하는 방식이며, 백그라운드 예약 수집이나 화면의 자동 반복 조회는 없습니다. 매체가 제공한 일부 목록이므로 시장 전체 뉴스량을 뜻하지 않습니다.

**게시 자료 다시 확인**으로 업데이트된 목록을 읽을 수 있습니다. 앞서 본 수집본 이후에 처음 발견한 출처만 새 자료로 알리며, 지도에서는 현재 날짜와 조건에 맞는 기업을 잠깐 초록색으로 강조합니다. 처음 화면을 열거나 같은 목록을 다시 읽을 때에는 강조하지 않습니다. 선택해 둔 날짜와 필터는 그대로 유지하며, 새 날짜는 버튼으로 이동합니다.

2026-10-15에는 산업·테마를 **4개에서 40개**, 기업 페이지를 **46개에서 137개**로 확대했습니다. 새 주제마다 대표 상장사 2~3곳을 연결해 107개 사업 근거를 추가했습니다. 지도에서 분야별로 주제를 선택할 수 있으며, 같은 회사가 여러 분야에서 하는 역할을 함께 볼 수 있습니다.

공식 동향 7건도 새 분야에 반영했습니다. 이 중 기존 현대건설 계약은 새 주제와 연결해 중복 사건으로 만들지 않았습니다. 나머지 분야의 최신 사건 전수 검토는 아직 아니며, 날짜 없는 사업 소개에는 확인일을 표시합니다. 전체 상장사나 모든 세부 테마를 다루는 단계는 아닙니다.

2026-10-14 20:59 KST 수집분과 10월 3일 이후 저장 자료를 검토해 **기업 25곳의 최신 이슈 52행**을 추가했습니다. 공시 원문과 공식 발표로 납입·최대주주 변경, 계약 정정, 잠정실적과 소송 합의를 확인했고, 기사 제목만 확인한 23개 사건은 그 한계를 표시했습니다. 일부 검색 결과와 당일 자료가 빠질 수 있으며 전체 공시·뉴스의 전수 반영은 아닙니다.

지도는 선택한 기업의 최신 이슈를 먼저 보여 줍니다. 특정 테마와 무관한 실적·철도·병원공사 등의 회사 이슈도 볼 수 있습니다. 각 이슈 날짜와 출처를 따로 표시하며, 위키 갱신일을 모든 자료의 기준일로 해석하지 않습니다.

2026-10-14에는 회사 41개와 주제 안내 4개의 분류·출처·상태 표시를 보완하고, 관계·이슈·테마 표시문장 208행을 검토했습니다. 공시된 위험과 인수 결정 단계도 구분했습니다. 이 검토가 모든 페이지의 모든 문장을 최신 자료로 확인했다는 뜻은 아닙니다.

여러 관계에 반복해서 나오는 상대회사 5개에는 확인된 관계와 출처를 모은 연결용 페이지를 추가했습니다. 사업 전반이나 주제 분류까지 새로 평가한 페이지와는 구분합니다.

관련 기업 표에는 예전 점수 순위 대신 분류와 근거를 보여 줍니다. 지도는 공개 제목 목록의 날짜별 기사·공시 수를 표시합니다. 사건 수와 비교 이력이 필요한 급증 수치는 아직 제공하지 않습니다.

## 자료를 반영하는 방법

1. 요청받은 범위의 공시·공식 발표와 기사 메타데이터를 확인합니다. 현재 뉴스 기사는 제목·링크를 사용하며 본문을 저장하거나 AI가 읽지 않습니다.
2. 근거에 맞는 짧은 설명을 작성하고 주체·기간·금액·진행 단계를 대조합니다.
3. 공개 위키에서 그래프와 관련 기업 표를 다시 만들고 링크·형식·상태·출처를 검사합니다.
4. 검토된 변경을 공개 저장소에 올리면 GitHub Actions가 Quartz 사이트를 빌드·배포합니다.

이 사이트는 검토된 정적 공개본입니다. 반복 수집·무인 게시·실시간 지도는 아직 운영하지 않습니다. 비공개 DB와의 대조 작업은 진행했지만 DB를 공개 위키의 원본으로 전환하는 일은 별도로 남아 있습니다.

## 공개 자료와 비공개 자료

공개 저장소에는 위키, 그래프 결과, 사이트 코드와 공개 가능한 출처 메타데이터를 둡니다. 뉴스 흐름에도 공개 조건을 확인한 제목·링크·날짜·출처만 전달합니다. 기존 `raw/` 파일은 이전에 공개한 자료 목록입니다. 새 전체 수집 기록과 중간 자료를 그대로 올리지 않으며, 예전 공개 수집 스크립트가 지금의 정책을 적용한다고 가정하지 않습니다.

기사 본문, 설계 자료, 검토 중간 기록, DB, 서버 운영 코드, 개인 메모와 인증 정보는 올리지 않습니다. API 키는 맥에서 키체인으로 관리하고, 허용된 클라우드 환경에서는 환경 변수를 사용합니다. 저장소와 GitHub Actions에 키를 넣지 않으며 기존 키 검사를 유지합니다.
